# 周末活动小助手 · Demo

**在线地址：** https://1903865053a-code.github.io/Red-s-repository/
（GitHub Pages 在境外，国内访问有时会慢或打不开）

## 怎么打开

双击 `index.html`，用 Chrome 或 Edge 打开。

## 这个 demo 想解决什么

微信群里接龙刷屏、被折叠，看不清谁去、谁去哪一段。

把周末切成 **上午 / 午饭 / 下午 / 晚饭 / 晚上 / 夜宵** 六个块，一个活动占连续几块，大家点进去选自己参加哪几段。

## 界面

- **周六、周日两列并排**，左边一列是时间块标签，一屏能看全整个周末
- 活动占哪几段，卡片就在对应位置占几格高度，跨段一眼可见
- 卡片上：标题、地点、备注、各时段人数、参加人头像，右上角小圆点是我的状态（绿=参加，黄=待定）
- 信息放不下的细节都在点开后的详情页里

## 能试什么

1. **报名**：点任意活动卡片 → 每个时段选「参加 / 待定 / 不去」→ 卡片上的头像和人数立刻更新
2. **发起**：点空白时段 → 再点相邻时段可以连着选 → 底部浮出「发起活动」
3. **换身份**（demo 特有）：右上角点自己的名字 → 选另一个人 → 看他的视角
4. **邀请 / 催办**：活动详情底部 → 复制文案 → 粘到微信群

## Demo 的边界

- 数据只存在**本机浏览器**里（localStorage），朋友打开看到的是同一份演示数据，不互通
- 微信头像昵称是模拟的。正式版由小程序获取（注意：微信现在也不能静默获取，需要用 `chooseAvatar` + `nickname` 输入框让用户点一下）
- 群组成员固定 6 人，没有真实的邀请链接

## 发给朋友

微信直接发 `index.html` 文件，让对方在**电脑**上用浏览器打开最稳。
手机上打开 HTML 文件比较麻烦（iOS 尤其），正式版会是小程序。

## 设计参考

调研了 Doodle / Rallly / When2meet / Partiful / Luma / Eventbrite / TimeTree / GroupMe / Band 等产品，主要借鉴和规避：

- **三态同时可见**：Doodle 靠单击/双击循环切换，用户根本发现不了「if need be」；Rallly 2026 改成三段控件后才清楚。所以这里用三个并排按钮。
- **确定和待定分开计数**：合并成一个「9 人」会让主办方订错位子。Facebook 的 Interested 僵尸就是这么来的。
- **邀请以群为单位**：Partiful / Luma 都是复制链接丢进群聊，不做逐个勾选通讯录。
- **「差谁没回」+ 一键催办**：这是 Partiful 的 `Invited` 过滤和 Luma 的 Blast 的价值所在，也是微信群接龙最痛的地方。
- **手机首屏用按天列表，不用月历**：TimeTree 月视图每天只显示 2-3 条且无提示，被用户投诉。
- **不照搬**：Discord 的在线状态和角色层级、GroupMe 的「一个活动一个群」、Slack 的 Canvas/Workflow，对朋友群都太重。
