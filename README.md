# 周末活动小助手 · Demo

**在线地址：** https://1903865053a-code.github.io/Red-s-repository/
（GitHub Pages 在境外，国内访问有时会慢或打不开）

## 怎么打开

双击 `index.html`，用 Chrome 或 Edge 打开。也可以直接开上面的在线地址。

## 这个 demo 想解决什么

微信群里接龙刷屏、被折叠，看不清谁去、谁去哪一段。

把一天按真实时间排开，标出 **上午 / 午饭 / 下午 / 晚饭 / 晚上 / 夜宵** 六个时段，活动占多长就显示多长。点进去选自己参加哪几段。

## 完整流程

1. **欢迎页** — 创建群组，或输入邀请码加入
2. **创建群组** — 群名 + 图标 + 你的名字 + 成员，一次建好，之后发活动不用再找人
3. **主界面** — 周六、周日两列并排，时间轴从 08:00 到 24:00
4. **选时间** — 长按空白处再往下拖，或者轻点一下（默认选中 1 小时）
5. **发起活动** — 精确到 15 分钟，可以上下微调开始和结束时间
6. **报名** — 每个环节选「参加 / 待定 / 不去」，点**确定**才保存
7. **工作日晚上** — 顶部切过去，用周一到周五的日期卡切换，只看 17:00 之后

## 几个刻意的设计

**报名是「草稿 + 确定」**
点参加/待定/不去只是改草稿，底部会出现「有未保存的修改」。点 × 或者点遮罩关掉 = 什么都没发生；点「确定」才真正写入。误触不会改掉自己的报名。

**活动精确到分钟，但按时段分组**
一个 11:30–19:30 的活动，会自动拆成 午饭 / 下午 / 晚饭 三段，每个人可以只参加其中几段。卡片上直接显示每段几个人，比如「下午 2 +1?」= 2 人去、1 人待定。

**没被占的时间看得见**
创建 10:00–12:00 的活动后，08:00–10:00 仍然是空的，下次可以直接在那里再选。活动在地图上按真实时长成比例显示。

**工作日晚上不硬塞 5 列**
375px 宽的手机上，5 列每列只有 60px，标题一定放不下。所以改成 5 个日期卡 + 单日时间轴，点哪天看哪天。这个取舍参考了 Notion Calendar（手机端只做 1/2/3 天）、Google Calendar 的 3 Day 视图、以及 Apple 日历竖屏不给周视图的做法。

**缩放**
右上角 − / ＋ 调整时间密度；电脑上可以 Ctrl + 滚轮；手机可以双指捏合。

## Demo 的边界

- 数据只存在**本机浏览器**里（localStorage），朋友打开看到的是同一份演示数据，不互通
- 微信头像昵称是模拟的，正式版由小程序处理
- 群组成员是本地数据，没有真实的邀请链接

## 设计参考

调研了 Doodle / Rallly / When2meet / Partiful / Luma / Eventbrite / TimeTree / GroupMe / Band / Notion Calendar 等产品：

- **三态同时可见**：Doodle 靠单击/双击循环切换，用户发现不了「if need be」；Rallly 2026 改成三段控件后才清楚
- **确定和待定分开计数**：合并成一个数字会让主办方订错位子（Facebook 的 Interested 僵尸）
- **邀请以群为单位**：Partiful / Luma 都是复制链接丢进群聊
- **「差谁没回」+ 一键催办**：微信群接龙最痛的地方
- **手机不塞 7 列**：Notion 官方只做 1/2/3 天，Google 3 Day 每列约 100px 已经接近可读下限
- **拖动选时间和滚动冲突**：Google 用「点空白 + 拖手柄」，FullCalendar 用 1 秒长按。这里用「轻点默认 1 小时 + 拖动扩展」，两种都留
