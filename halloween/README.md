# 给哈基米的万圣节小卡片

一个可以直接发链接的网页：她点开，一盏一盏点亮南瓜灯，敲开一扇门，最后收到一封信。

- **线上地址**：https://1903865053a-code.github.io/Red-s-repository/halloween/
- **手机上效果最好**，微信里直接打开就行。

---

## 想改点什么？只需要改一个文件

打开 `config.js`，改完保存、刷新网页就能看到。

文件最上面那几行就是要改的：

```js
const SITE = {
  herName: '哈基米',      // ← 她叫什么
  signature: '爱你的',    // ← 信的落款
  fromName: '',          // ← 落款后面要不要接你的名字，比如填 '小陈'
  startDate: '',         // ← 填 2025-10-31，信的末尾会多一行「在一起第 N 天」
  theme: 'halloween',    // ← 主题
  sound: true,           // ← 一开始有没有声音
};
```

再往下是 `STORY` —— **你们俩的真实内容**，跟节日无关，换主题也不会丢：

```js
const STORY = {
  places: [ ... ],   // 五盏灯，一盏一个地方。数量可以改，3 盏 6 盏都行
  letter: [ ... ],   // 那封信，一行一段
};
```

最后是 `THEMES`，里面 `copy` 是每个节日的「外壳」文案（封面标题、敲门、给糖/捣蛋、落款）。**想改哪句改哪句，引号里的字随便改，引号和行尾的逗号别删**。

几个最值得改成「只有你们俩懂」的地方：

| 位置 | 现在写的是 | 建议改成 |
| --- | --- | --- |
| `lanternLines` | 第一盏，给你照路。 | 换成你们之间真实的小事 |
| `lanternLines` 第三句 | 第三盏……你把糖藏哪了？ | 换成你们的梗 |
| `letter` | 万圣节的糖会吃完…… | 换成真想跟她说的话 |
| `bye` | 万圣节快乐，{name}。 | 保留 `{name}` 会自动换成她的称呼 |

> 越具体越动人。「你穿灰毛衣那天」比「你是我生命中的阳光」好一百倍。

## 换成别的节日

**方法一（推荐）**：把 `config.js` 里的 `theme` 改成 `'christmas'` 或 `'valentine'`。

**方法二（先看看效果）**：在网址后面加参数，不用改文件：

- `.../halloween/?theme=christmas` 圣诞版
- `.../halloween/?theme=valentine` 情人节版

三套主题各自有：配色、飘落的东西（余烬 / 雪花 / 爱心）、点亮的物件（南瓜灯 / 小蜡烛 / 心灯）、以及全套文案。
想加第四套主题，照着 `THEMES` 里任意一套复制一份，改颜色和文字即可 —— 不用动 `app.js`。

## 文件都是干什么的

| 文件 | 作用 | 需要改吗 |
| --- | --- | --- |
| `index.html` | 页面骨架 | 基本不用 |
| `config.js` | **称呼、文案、主题、颜色** | ← 只改这个 |
| `style.css` | 样式（颜色会从 config 里读） | 想微调版式才动 |
| `app.js` | 交互逻辑（点亮、敲门、打字机） | 不用 |

## 改完怎么上线

在这个文件夹里：

```bash
git add halloween
git commit -m "更新卡片文案"
git push
```

推完等 1～2 分钟，刷新线上地址就能看到。

> 微信内置浏览器缓存很凶。改完如果她那边还是旧版，
> 把 `index.html` 里三处 `?v=2` 的数字各加一（改成 `?v=3`）再推一次，缓存就会强制刷新。

## 几个要知道的事

- **这个页面是公开可访问的。** 已经加了 `noindex`（搜索引擎不收录），但拿到链接的人都能打开。如果介意，可以换成随机路径，或者单独建一个仓库再删掉。
- **国内打开 GitHub Pages 有时慢或者打不开。** 让她先试一次；如果不行，可以换 Cloudflare Pages / 国内对象存储，代码不用改。
- **声音是代码合成的，没有音频文件**，所以加载很快；右上角的喇叭随时可以关。
- 页面已经处理过：手机竖屏、刘海屏、微信内置浏览器、系统「减少动态效果」、长按不弹「保存图片」。
- 不想让她看到某句话？直接删掉那一行（连同行尾逗号）就行，不会报错。
