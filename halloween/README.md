# 给哈基米的万圣节小卡片

一条能一直往下翻的长卷：一年一章，照片滑到才「洗」出来，最后是一扇门和一封信。

- **线上地址**：https://1903865053a-code.github.io/Red-s-repository/halloween/
- 手机上效果最好，微信里直接打开就行。

---

## 页面怎么走

```
封面（不给糖就捣蛋）
  ↓
2019 ── 05.01 假期，跑去找她
       ── 05.10 放学，在地铁站一人一瓶啤酒
       ── ……
       ── 12.08 三水的摩天轮
  ↓
（以后每一年都接在这里）
  ↓
门 → 敲三下 → 给糖 / 捣蛋 → 拆信 → 从头再看
```

照片是进到屏幕里才显影的，所以往下滑的过程本身就是在「洗照片」。

---

## 加一年：只改 config.js

打开 [config.js](config.js)，找到 `STORY.years`，在最后一年后面加一段：

```js
{
  year: '2020',
  line: '一句话概括这一年。',
  moments: [
    {
      date: '03.14',
      text: '那天做了什么。',
      note: '补一句细节，可以留空。',
      photos: [
        { src: 'photos/2020/0314-xxx.jpg', alt: '图里是什么' },
      ],
    },
  ],
},
```

然后：

1. 在 `halloween/photos/` 里新建一个年份文件夹，比如 `photos/2020/`
2. 把照片放进去，文件名用英文和数字（`0314-park.jpg` 这样）
3. `src` 路径和文件名对上就行
4. 一年里想放几个 moment 都行；一个 moment 放 1～4 张照片，手机上可以左右滑

**代码一行都不用改。** 年份多了，右侧会自动出现年份导航，能直接跳。

## 照片的要求

- jpg / png 都行，横竖都行，我会统一压到长边 1400 像素（一张两三百 KB）
- 尽量别裁剪，留原图，页面里会自动按比例框好
- 放在这个仓库里就是公开的（已加 noindex，但拿到链接的人能看到）——不想被看到的别放

---

## 改文字

| 想改 | 在哪 |
| --- | --- |
| 称呼、落款、在一起的第一天 | `SITE` 最上面几行 |
| 封面标题 / 副标题 / 按钮 | `STORY.cover` |
| 每年的标题句、每个瞬间的日期和句子 | `STORY.years` |
| 门 / 给糖 / 捣蛋 的台词 | `STORY.finale` |
| 那封信 | `STORY.letter`，一行一段 |

改的时候只要记住：**引号里的字随便改，引号和行尾的逗号别删。**

---

## 换节日配色

`SITE.theme` 改成 `'christmas'` 或 `'valentine'`。
想先看看效果不用改文件，网址后面加 `?theme=christmas` 就行。

主题只管颜色和飘落的东西（余烬 / 雪 / 爱心），文字是另一套，换主题不会丢。

---

## 改完怎么上线

```bash
git add halloween
git commit -m "加 2020"
git push
```

推完等 1～2 分钟，刷新线上地址就能看到。

> 微信缓存很凶。如果她那边还是旧版，把 `index.html` 里三处 `?v=3` 的数字各加一（改成 `?v=4`）再推一次。

---

## 文件都是干什么的

| 文件 | 作用 | 要改吗 |
| --- | --- | --- |
| `config.js` | **所有文字 + 所有照片路径 + 主题色** | ← 只改这个 |
| `photos/2019/` | 压好的照片 | 加照片 |
| `index.html` | 页面骨架 | 不用 |
| `style.css` | 样式 | 想调版式才动 |
| `app.js` | 交互逻辑 | 不用 |
